# 数据来源与时间口径

接口字段核对参考 [AKShare 官方股票文档](https://akshare.akfamily.xyz/data/stock/stock.html)、[指数文档](https://akshare.akfamily.xyz/data/index/index.html)和 AKShare 1.19.3 的 MIT 开源代码。当前下载适配器为独立的 urllib 实现，运行不依赖 akshare 包。

| 数据 | 来源 | 本版处理 |
|---|---|---|
| 当前 A 股名册和行情 | [东财行情](https://quote.eastmoney.com/center/gridlist.html#hs_a_board)，不可用时切换[新浪](https://vip.stock.finance.sina.com.cn/mkt/#hs_a) | 校验分页和重复代码；两个来源的覆盖范围可能不同 |
| 个股历史 | 腾讯证券公开历史接口 | 前复权价格；日方向按相邻收盘价变化计算；成交额统一为元 |
| 上证指数历史 | 东财指数历史接口 | 日线用于技术计算；周线接口不可用时按日线聚合 |
| 上交所期权 | [每日统计](https://www.sse.com.cn/assortment/options/date/) | 认购、认沽成交与持仓数量分别汇总 |
| 深交所期权 | [日度概况](https://investor.szse.cn/market/option/day/index.html) | 与上交所分别保留，再计算跨所合计 |
| 股东增减持 | [东财股东增减持](https://data.eastmoney.com/executive/gdzjc.html) | 公告日过滤与分月；股数单位为万股 |
| 董监高变动 | [东财董监高明细](https://data.eastmoney.com/executive/list.html) | 股数和金额分别统计；没有与股东表直接合并 |
| 十年国债收益率 | [东财中美国债收益率](https://data.eastmoney.com/cjsj/zmgzsyl.html) | 使用百分数单位，和 PE 同日期匹配 |
| PE | [乐咕乐股上证估值](https://legulegu.com/stockdata/shanghaiPE)、[沪深300估值](https://legulegu.com/stockdata/hs300-ttm-lyr) | 分别保留市场平均 PE 和滚动 PE；不混成一条序列 |

## 单位与完整性

新浪成交量原字段为股，内部快照容器转换为手；指标计算时统一回股。腾讯历史的不同证券成交量单位可能不同，优先用同日新浪数量校准，无法直接对照时记录金额与价格的近似校准方式。成交额和成交量两个 TRIN 不混用。

历史换手率采用同日跨源校准，未通过的记录不填为 0，其有效分母单列。股东记录只去除相同事件键的重复项；累计披露区间是否互相重叠尚未全部审计。

每个成功响应缓存保存请求 URL、抓取时间和规范化响应 SHA-256。`analyze.py` 另生成输入文件哈希清单；`verify_inputs.py` 校验本地输入是否与该清单一致。它不能证明上游数据本身正确。

## 历史分析的限制

1. 最新股票名册不是历史名册。当前名册回溯会遗漏退市证券，也不自动恢复过去的 ST、行业或指数成员状态。
2. 前复权价格可能随新分红和公司行动修订；两位小数舍入也可能改变平盘判断。它不是交易所未舍入的每日涨跌标志。
3. 股东变动截止日与公告日可能相差数日。公告日过滤避免使用尚未公布的记录，但事后修订和累计区间仍需进一步核对。
4. 董监高表缺少经过验证的历史公告时间，按变动日的结果不能直接用作当时可知的回测输入。
5. 新浪快照只有时分秒，未给完整交易日期；它按抓取日归属，不能用于声称重建任意历史快照。
6. 期权范围不含中金所；原作者是否采用不同标的、期限或期权类型未知。
7. 当前免费 PE 响应是稀疏/月度样本，没有填成日频，无法据此提供可靠的 252 日估值统计带。

## 本地目录

`data/` 保存标准化输入，`cache/` 保存逐请求响应，`results/` 保存新计算结果。这些目录被 Git 忽略。仓库只保留 `examples/2026-10-23/` 中的小体积汇总结果和图表。

自动采集依赖第三方接口状态、字段与服务条款。需要更严格的历史全集或时间点数据时，应替换为具有相应覆盖与使用权限的数据源，并保留相同的质量检查。
